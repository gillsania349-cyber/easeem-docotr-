# PakMed — Next.js

Converted from the Vite React prototype. **Same design and UI** — no visual redesign.

## Run

```bash
cd next
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack (this folder)

- Next.js (App Router)
- React client component: `components/PakMedApp.jsx` (ported as-is)
- Tailwind CSS
- lucide-react icons

## Notes

- Still a frontend prototype (demo auth/OTP, seed data). Supabase / Cloudinary come later.
- Original Vite app remains in the parent folder unchanged.
